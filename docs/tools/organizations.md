# Azure DevOps Organizations Tools

> **Removed** — `list_organizations` and `get_me` are **not available** in this server.
>
> Both endpoints rely on Azure DevOps Services-only APIs (`vssps.dev.azure.com`, `app.vssps.visualstudio.com`) that do not exist on Azure DevOps Server (on-premises). This server targets on-premises deployments exclusively, so these tools have been removed.
>
> To discover which projects exist on your server, use [`list_projects`](./projects.md#list_projects) instead.
